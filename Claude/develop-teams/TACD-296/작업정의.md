# TACD-296: [시너지 > 정보 UI] - 시너지 아이콘을 클릭하면 효과 설명과 소환수 목록을 확인할 수 있다

> 상위 이슈: TACD-252 [전장 - 시너지] - 시너지 정보 UI

## 요구사항

시너지 목록 패널에서 시너지 아이콘을 클릭하면 상세 패널이 열린다.
상세 패널에는 시너지 효과 설명, 티어별 효과 수치, 해당 시너지를 보유한 소환수 목록이 표시된다.
소환수 목록에서 전장에 배치된 소환수와 미배치 소환수를 시각적으로 구분할 수 있다.

## 배경지식

- 시너지 상세 패널은 기획 이미지의 "초록색 영역"에 해당한다. TFT의 시너지 클릭 시 나타나는 상세 정보 패널을 참고한다.
- TACD-295에서 시너지 목록 패널(SynergyListPanel)과 인디케이터(SynergyIndicator)가 이미 구현되었다. 인디케이터의 클릭 이벤트가 SynergyInfoPanel을 거쳐 SynergyDetailPanel.Show(SynergyActivation)까지 전달되는 구조가 준비되어 있다.
- SynergyDetailPanel은 현재 껍데기 상태(Show/Hide만 존재)이며, 이 작업에서 내부를 구현한다.
- 시너지 효과 설명(SynergyDefinitionData.Description)에는 `@ConstantName@` 또는 `@ConstantName*N@` 형태의 플레이스홀더가 포함될 수 있다. 플레이스홀더 치환은 별도 일감에서 구현 예정이며, 이번 작업에서는 Description 원본을 그대로 표시한다.
- 소환수 목록은 SynergyManager가 보유한 역방향 맵(UnitLoadOutData → SynergyDefinitionData)을 통해 해당 시너지에 속하는 소환수를 조회할 수 있다. UI에서는 소환술사 효과와 소환수 특성을 구분하지 않는다.
- 소환수의 전장 배치 여부는 Defender.Placement가 BattleArea인지로 판별한다.

## 완료 정의

- CD-1: 시너지 아이콘 클릭 시 상세 패널이 열린다.
- CD-2: 이미 열린 상태에서 같은 시너지를 다시 클릭하면 패널이 닫힌다.
- CD-3: 다른 시너지를 클릭하면 해당 시너지의 정보로 교체된다.
- CD-4: 상세 패널에 시너지 아이콘과 이름이 표시된다.
- CD-5: 상세 패널에 시너지 효과 설명이 표시된다. (플레이스홀더 치환은 별도 일감에서 구현한다)
- CD-6: 상세 패널에 모든 티어의 필요 카운트와 효과 수치가 목록으로 표시된다.
- CD-7: 현재 활성 티어와 비활성 티어가 시각적으로 구분된다 (색상, 투명도 등).
- CD-8: 해당 시너지를 보유한 소환수 목록이 아이콘으로 표시된다.
- CD-9: 전장에 배치된 소환수와 미배치 소환수가 시각적으로 구분된다 (활성/비활성).
- CD-10: 소환수 배치/제거 시 소환수 목록의 활성/비활성 상태가 실시간으로 갱신된다.
- CD-11: 닫기 버튼 클릭 시 상세 패널이 닫힌다.
