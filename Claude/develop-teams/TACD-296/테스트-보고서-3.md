## 스킵 사유 요약

단위 3의 완료 정의(CD-8, CD-9, CD-10) 중 UI 관련 로직은 MonoBehaviour 및 Unity 컴포넌트에 전면 의존한다.

- **Image.sprite**: 소환수 아이콘 바인딩 (`CD-8`)
- **CanvasGroup.alpha**: 배치 상태 시각적 구분 (`CD-9`)
- **Instantiate**: 소환수 슬롯 동적 생성 (`CD-8`)
- **DefenderManager 싱글톤**: 전장 배치 여부 판별 (`CD-9, CD-10`)
- **GlobalEventBus 이벤트 → 실시간 갱신**: OnDefenderPlacementChangedEventDto, OnDefenderChangedEventDto (`CD-10`)

`SynergyManager.GetUnitsForSynergy()`는 내부 `_unitSynergyMap`만 참조하는 순수 조회 로직으로, 리플렉션으로 맵을 세팅하여 5개 케이스 모두 통과했다.
