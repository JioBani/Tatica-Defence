## 스킵 사유 요약

단위 1의 완료 정의(CD-1, CD-2, CD-3, CD-4, CD-11)는 모두 `SynergyDetailPanel`과 `SynergyInfoPanel`의 MonoBehaviour 동작에 의존한다.

- **gameObject.activeSelf**: Show()/Hide()의 패널 열기/닫기 판정 (`CD-1, CD-2, CD-3, CD-11`)
- **Image.sprite / TMP_Text.text**: 아이콘·이름 바인딩 (`CD-4`)
- **Button.onClick**: closeButton 클릭 → Hide() 연결 (`CD-11`)

위 모든 의존성은 Unity 씬 환경 없이는 에디터 단위 테스트에서 초기화할 수 없다. 에디터 테스트 대신 PlayMode 통합 테스트 또는 씬에서 수동 확인이 적합하다.
