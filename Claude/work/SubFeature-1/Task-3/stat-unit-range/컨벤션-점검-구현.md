### 식별된 위반 (1건)

- **VR-1 (I-19 조기 return 지양)**: `UnitStatSheet.ResolveBaseValue` 가 `if(HasStat) return A; return B;` 의 조기 return(완결 지점 2곳). 단순 이분기이므로 단일 완결(삼항)이 권장.

## Pass 2 — 위반 수정

- **VR-1 수정**: `ResolveBaseValue` 를 삼항 단일 return 으로 변경(`return HasStat ? GetStat : Default;`). 완결 지점 1곳. 행위 동일(F-1 무관), 주석 보존.

## 보류(수정 안 함) 항목 — 근거

- **UnitStatKind switch 다중 존재**(GetStat·HasStat·시트 Get/Enumerate·카탈로그 Get·UI GetDisplayName): explore 가 짚은 기존 "enum 키-필드 이중 보유(명시 필드+switch)" 패턴 추종. 카탈로그 Get 은 정의 테이블 자체이고 HasStat 은 기존 GetStat 패턴 일관 추종(DD-2 동종 일관성). enum→딕셔너리 전면 전환은 Task-2 커밋 코드까지 번지는 범위 외 구조 리팩토링(F-4)이라 본 단계 수정 안 함. (기존 코드 스멜 — 별도 추적 가능)
- **FormatStatValue 가 StatUnit 확장인데 클래스명이 UnitStatKindExtensions**: 클래스 리네임은 취향/범위(F-2/F-4) — 보류.
