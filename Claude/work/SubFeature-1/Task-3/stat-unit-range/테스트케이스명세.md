# 테스트케이스 명세 — stat-unit-range (Task-3, SR 그룹 B)

> 구현 단위 `stat-unit-range` 의 요구사항 테스트 케이스 도출 근거.
> 검증 기준: UR Req-3 / SR DoD-S8~S10 의 완료 정의(**정정 반영본** — 치명타 배율 = 배수 1.0~∞ 기본 1.5)(코드 추종 금지).
> 테스트 코드: `Assets/Tests/Editor/StatUnitRangeTests.cs` (EditMode, 순수 로직 → EditMode 격리).

## 범위 경계

- **본 단위 대상**: DoD-S8(단위·범위·기본값 단일 정의)·DoD-S9(최종값 강제: 범위 클램프+정수화)·DoD-S10(값 강제·표시가 동일 정의 공유).
- **전제(범위 밖)**: Task-2(10종 단일화, 커밋 159cc0b) 결정은 본 단위가 검증하지 않는다.

## 단위·범위 단일 진실 (DoD-S8 정정 반영본 — 검증 기준 표)

| 능력치 | 단위(StatUnit) | 범위(min~max) | 기본값 |
|--------|------|------|--------|
| 최대 체력 | Integer | 1 ~ ∞ | (—, DD: 1) |
| 공격력 | Integer | 0 ~ ∞ | (—, DD: 0) |
| 방어력 | Percent | 0 ~ 0.95 (0~95%) | (—, DD: 0) |
| 공격 속도 | Float | 0.1 ~ ∞ | (—, DD: 0.1) |
| 사거리 | Float | 0 ~ ∞ | (—, DD: 0) |
| 이동 속도 | Float | 0 ~ ∞ | (—, DD: 0) |
| 치명타 확률 | Percent | 0 ~ 1 (0~100%) | **0** (요구사항 명시) |
| 치명타 배율 | Multiplier | 1.0 ~ ∞ | **1.5** (요구사항 명시) |
| 쿨타임 감소 | Percent | 0 ~ 0.9 (0~90%) | (—, DD: 0) |
| 피해 증가 | Percent | 0 ~ ∞ | (—, DD: 0) |

> 기본값 "(—)" 종류는 요구사항이 값을 명시하지 않으며, "범위 하한을 기본값으로" 는 DD 정책이다. 따라서 요구사항 테스트는 **요구사항이 명시한 기본값(치명타 확률 0·치명타 배율 1.5)** 만 fallback 으로 검증한다.

## 테스트 케이스 분해

### DoD-S8 — 단위·범위·기본값 단일 진실

- **결정 테이블(종류×단위×범위)**: 10종 각각 카탈로그가 단위·하한·상한을 요구사항 표대로 정의. `[TestCaseSource]` 로 10행 압축(∞ 값 때문에 인라인 `[TestCase]` 불가 → 소스 메서드). → `Test_S8_CatalogDefinesUnitAndRangePerRequirement`
- **유스케이스(예외 흐름=미입력 fallback)**: 자산 미입력 시 요구사항 명시 기본값 적용. 치명타 배율 1.5(미입력이 0→하한 1.0이 아니라 1.5 임을 구분), 치명타 확률 0. `[TestCase]` 압축. → `Test_S8_MissingAssetValueFallsBackToRequirementDefault`

### DoD-S9 — 최종값이 단위·범위를 따른다 (경계값·동치분할)

- **경계값(상한)**: 상한 초과 입력 → 상한 클램프. 방어력 0.99→0.95 / 쿨감 0.95→0.9 / 치확 1.5→1.0. `[TestCase]`. → `Test_S9_FinalValueClampedToUpperBound`
- **경계값(하한)**: 하한 미만 입력 → 하한 클램프. 치명타 배율 0.5→1.0 / 공속 0.05→0.1 / 체력 0→1 / 공격력 -5→0 / 방어력 -0.1→0. `[TestCase]`. → `Test_S9_FinalValueClampedToLowerBound`
- **동치분할(정수 단위)**: 정수 단위 최종값 정수화. 공격력 10.6→11·10.4→10 / 체력 100.7→101. `[TestCase]`. → `Test_S9_IntegerUnitFinalValueIsInteger`
- **동치분할(실수 단위)**: 실수 단위는 정수화 안 함. 공속 1.25→1.25. → `Test_S9_FloatUnitFinalValueNotRounded`
- **유스케이스(수정자 적용 후 강제)**: 수정자로 산정된 최종값에도 범위 강제. 방어력 base 0 +99% 수정자 → 0.95. → `Test_S9_RangeEnforcedOnModifiedFinalValue`

### DoD-S10 — 값 강제와 표시가 동일 정의를 공유

- **결정 테이블(단위×표기)**: 단일 진실의 단위를 읽어 표기. 방어력/치확/쿨감 %, 치명타 배율 "1.5x", 사거리/이동속도 소수(F2), 정수 단위 정수. `[TestCase]` 8행. → `Test_S10_DisplayUsesUnitFromSingleSourceDefinition`
- **유스케이스(단일 진실 정합)**: 시트가 생성한 각 능력치의 메타데이터(값 강제 근거)가 표시가 참조하는 카탈로그와 일치(10종 순회). → `Test_S10_SheetStatsCarrySameMetadataAsCatalog`
