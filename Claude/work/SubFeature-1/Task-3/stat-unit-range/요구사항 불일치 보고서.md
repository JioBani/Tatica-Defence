## 범위 외 회귀

### MIS-001: 시너지 컨트롤러 배치-디스패치 경로의 수정자 미적용 (무관 회귀 — Task-2 부터 연속)

- 라벨: **무관 회귀 (컨트롤러 디스패치 경로, 본 단위 범위 밖)**
- 실패 테스트(대표): `ArcanistSynergyControllerTests`(2건, 기대 35/25·실제 base 10), `SynergyControllerTests`(3건: TwoDefendersEnter_TierActivates / NewDefenderEntersWhileActive / DefenderLeavesAndReenters, 기대 125·실제 base 100).
- 기대 동작: 배치 이벤트 → `SynergyController` 가 SSE 를 능력치에 적용 → 능력치 = base + 버프.
- 실제 동작: 컨트롤러 경로에서 수정자가 적용되지 않아 능력치가 base 에 머무름.

**인과 점검 (무관 판정 근거)**:
1. 1순위 코드 영향면: 본 단위 변경은 능력치 메타데이터(단위·범위·기본값)·`UnitStat` 정규화·`UnitStatSheet` 생성·`UnitStatKindExtensions`/`StatCell` 표기뿐이다. 실패 경로(`SynergyController.HandlePlacementChanged`→`StatusEffectController.Apply`→`SSE.OnApply`→수정자 부여)의 디스패치·티어 활성화는 본 단위에서 변경하지 않았다.
2. 버프 값이 적용됐다면 125/35/25 (정수·범위 내)로 클램프·정수화 영향이 없다. 실패는 "적용 자체가 안 됨"(base 값)으로, 본 단위의 클램프/정수화와 무관하다.
3. 직접 효과 테스트는 GREEN: `Gunslinger`/`Arcanist*`/`Warmonger` SynergyStatusEffect 등 스탯-소비 시너지 효과 85건이 Task-3 하에서 전부 통과 → 수정자의 능력치 적용 메커니즘은 정상. 실패는 컨트롤러 디스패치 경로에 한정.
4. Task-2 에서 동일 군(ArcanistSynergyControllerTests)을 이미 무관 회귀로 확정했고, 본 단위 변경 전후 동일하게 실패한다(Task-3 프로덕션은 디스패치 경로 미변경).
- 결론: **DoD-S8~S10 과 무관**. 컨트롤러 디스패치 경로의 기존 실패. 별도 추적 권장.

### MIS-002: 시너지 상세 패널 UI(UI Toolkit) 테스트 실패 (무관 회귀 — 기존)

- 라벨: **무관 회귀 (UI Toolkit 패널 테스트, 본 단위 범위 밖)**
- 실패 테스트(대표): `SynergyDetailEffectSectionTests`·`SynergyDetailMemberListTests`·`SynergyDetailPanelLifecycleTests` (tier-list 자식 수 3 vs 5, USS 클래스 부재, `UIDocument` 미부착 [Error] 로그, IndexOutOfRange 등).
- 기대/실제: UI Toolkit 패널의 USS 클래스·tier 항목·문서 부착 관련 검증으로, 능력치 값과 무관.

**인과 점검**:
1. 출처: TACD-296(시너지 효과 정보 표시) 산물. SubFeature-1 스탯과 무관한 시너지 UI 영역.
2. 실패 사유(UIDocument 미부착·USS 클래스·tier 정의 수)는 능력치 메타데이터/표기와 코드 의존 경로가 없다. 본 단위가 바꾼 `UnitStatKindExtensions.FormatStatValue`·`StatCell` 은 *능력치 셀 표기*만 담당하며 시너지 상세 패널 구조와 무관.
3. 본 단위는 이 테스트 파일들을 수정하지 않았고, Task-3 프로덕션도 시너지 상세 패널 코드를 변경하지 않았다.
- 결론: **DoD-S8~S10 과 무관**. 시너지 UI 패널 테스트의 기존 구조적 실패(EditMode UI Toolkit 라이프사이클 등). 별도 추적 권장.

> 비고: 전체 스위트 실행 결과는 실패 목록이 캡(truncated)되었으나, 관측된 실패는 모두 위 두 군(컨트롤러 디스패치·시너지 UI)에 속한다. 본 단위가 직접 건드린 스탯 경로(메타데이터·정규화·표기) 및 스탯 소비처(시너지 효과·통합 85건)는 전부 GREEN 으로, 본 단위 유발 회귀는 없다.
