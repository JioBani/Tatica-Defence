# 구현 변경 영역 — stat-unit-range (Task-3)

> 구현 단위 `stat-unit-range` (SR 그룹 B, DoD-S8~S10) 변경 영역 메모. test 멤버 브리핑·불일치 해소·리펙토링 참조용. 기준: Task-2 커밋(159cc0b) 위.

## 범위
10종 능력치의 단위·범위·기본값을 데이터 모델 단일 진실로 정의하고, 최종값을 그 정의로 강제(범위 클램프 + 정수화)하며, UI 표기가 같은 정의를 참조하게 통합.

## 단일 진실 메타데이터 (DoD-S8)
`UnitStatMetadataCatalog.Get(UnitStatKind)` 가 반환. % 단위는 0~1 저장(표시 ×100%), 상한 무제한=∞.

| Kind | StatUnit | Min | Max | Default | CalcMode |
|---|---|---|---|---|---|
| MaxHealth | Integer | 1 | ∞ | 1 | Additive |
| Attack | Integer | 0 | ∞ | 0 | Additive |
| Defense | Percent | 0 | 0.95 | 0 | SeparatedMultiplicative |
| AttackSpeed | Float | 0.1 | ∞ | 0.1 | Additive |
| AttackRange | Float | 0 | ∞ | 0 | Additive |
| MoveSpeed | Float | 0 | ∞ | 0 | Additive |
| CriticalChance | Percent | 0 | 1 | 0 | Additive |
| CriticalDamageMultiplier | Multiplier | 1.0 | ∞ | 1.5 | Additive |
| CooldownReduction | Percent | 0 | 0.9 | 0 | Additive |
| DamageDealtIncrease | Percent | 0 | ∞ | 0 | Additive |

## 변경된 프로덕션 파일

### 신규 (3)
1. `Assets/Scenes/Battle/Feature/Unit/Unit/UnitStats/StatUnit.cs`: enum `StatUnit { Integer, Float, Percent, Multiplier }`.
2. `.../UnitStats/UnitStatMetadata.cs`: readonly struct. 필드 Unit·Min·Max·Default·CalculationMode. 생성자(상한<하한 시 ArgumentException). `float Normalize(float raw)` = Clamp(min,max) + Integer면 Mathf.Round.
3. `.../UnitStats/UnitStatMetadataCatalog.cs`: class. `UnitStatMetadata Get(UnitStatKind)` switch(위 표). 미정의 kind → ArgumentOutOfRangeException.

### 수정 (5)
4. `.../UnitStats/UnitStats.cs` (UnitStat): 생성자 `UnitStat(UnitStatMetadata)` (구 `(StatCalculationMode)` 대체). 필드 `_mode`→`_metadata`. `UnitStatMetadata Metadata` 노출. `Recalculate`: 합산모드는 `_metadata.CalculationMode`, 산정 후 `_metadata.Normalize(raw)` 로 최종값 강제.
5. `.../UnitStats/UnitStatSheet.cs`: 카탈로그 필드(`_catalog = new()`). 10개 UnitStat 필드를 생성자에서 `new UnitStat(_catalog.Get(kind))` 로 생성(구 field initializer·Defense 전용 모드 제거). `Init`/`RefreshBaseStats` base 주입을 `ResolveBaseValue(data, kind, star)` 경유 — 자산 미입력(`!data.HasStat(kind)`)이면 `_catalog.Get(kind).Default` fallback.
6. `Assets/Common/Data/Units/UnitStatsByLevel/UnitStatsByLevelData.cs`: `bool HasStat(UnitStatKind)` 추가(record.HasAnyValue 기반 switch).
7. `Assets/Scenes/Battle/Feature/Ui/StatInfoPanel/Scripts/UnitStatKindExtensions.cs`: `FormatStatValue` 를 `this StatUnit unit` 기반으로 변경(Percent→×100%, Multiplier→Nx, Float→F2, Integer→F0). `using Scenes.Battle.Feature.Units.UnitStats` 추가. `GetDisplayName` 유지.
8. `.../StatInfoPanel/Scripts/StatCell.cs`: `Bind` 의 값 표기를 `stat.Metadata.Unit.FormatStatValue(stat.CurrentValue)` 로 변경(UI가 UnitStat 메타 참조 — 별도 카탈로그 불요).

## 동작 변화 (의도된 것 — 검증 포인트)
- 최종값이 범위로 클램프됨: 방어력 ≤0.95, 쿨감 ≤0.9, 치명타확률 ≤1.0, 치명타배율 ≥1.0, AttackSpeed ≥0.1, MaxHealth ≥1.
- 정수 단위(Attack·MaxHealth) 최종값 정수화(Mathf.Round).
- 자산 미입력 능력치는 0 대신 메타 기본값(예: 치명타배율 1.5, AttackSpeed 0.1).
- UI 표기: 방어력 % 표시(기존 정수 표시 정정), 사거리·이동속도 F2(소수), 치명타배율 "1.5x" 보존.

## 마이그레이션
- 자산 마이그레이션 없음(DoD-S8 치명타배율=배수 1.5 확정으로 기존 값·코드 일치). 범위 밖 기존 입력값은 런타임 클램프로 수렴(자산 수정 불요).

- 플레이모드 1회 진입 → 새 Error/Exception 없음(스탯 시트 생성·Init·Normalize 정상).
- 기존 테스트 어셈블리 컴파일 에러(test 영역): `UnitStatTests.cs`(구 UnitStat 생성자), `UnitStatKindHelperTests.cs`(구 FormatStatValue). 새 API 기준 갱신 필요.
