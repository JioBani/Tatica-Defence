# 구현 변경 영역 — stat-set-unification (Task-2)

> 구현 단위 `stat-set-unification` (SR 그룹 A, DoD-S1~S7) 의 변경 영역 메모. test 멤버 브리핑·불일치 해소·리펙토링 참조용.

## 범위
능력치 종류 집합 14종 → 10종 단일화. 공격력·방어력 물리/마법 분리 제거(단일화), 상태저항력·받는 피해 감소 제거, DamageType enum 제거, Warmonger 시너지 단일 Defense 재배선.

## 최종 능력치 10종 (`UnitStatKind`, 명시 int)
MaxHealth=0, Attack=1, Defense=3, AttackSpeed=5, AttackRange=6, MoveSpeed=7, CriticalChance=8, CriticalDamageMultiplier=9, CooldownReduction=10, DamageDealtIncrease=12
- 결번: 2(구 MagicAttack)·4(구 MagicDefense)·11(구 StatusResistance)·13(구 DamageReduction) — 스킬 .asset statKind 직렬화 안정성 위해 생존 멤버 정수 보존.

## 변경된 프로덕션 파일
1. `Assets/Common/Data/Units/UnitStatsByLevel/UnitStatsByLevelData.cs`
   - `UnitStatKind` enum 10종(명시 int). SO 필드: `physicalAttack`→`attack`(`[FormerlySerializedAs("physicalAttack")]`), `physicalDefense`→`defense`(`[FormerlySerializedAs("physicalDefense")]`). `magicAttack`·`magicDefense`·`statusResistance`·`damageReduction` 필드 제거. `GetStat` switch 10분기.
2. `Assets/Scenes/Battle/Feature/Unit/Unit/UnitStats/UnitStatSheet.cs`
   - `UnitStat` 필드 10종. `Attack`=Additive, `Defense`=SeparatedMultiplicative(기존 물리/마법 방어 모드 계승). `Get`/`Enumerate` 10종.
3. `Assets/Scenes/Battle/Feature/Unit/Damage/DamageCalculator.cs`
   - `DamageType` 파라미터 제거(4 오버로드). 단일 `Attack`/`Defense` 채널. **받는 피해 감소 단계 제거**. 입히는 피해 증가 유지. 파이프라인: 기본데미지→치명타→방어력→피해증가→버림(최소0).
4. `Assets/Common/Data/Damage/DamageType.cs` — **삭제**.
5. `Assets/Scenes/Battle/Feature/Unit/Casting/Executable/RangeAttackExecutor.cs` — DamageType.Physical 인자 제거.
6. `Assets/Scenes/Battle/Feature/Unit/Skills/Scripts/Skills/FireArrow/FireArrowExecutor.cs` — DamageType.Magical 인자 제거.
7. `Assets/Scenes/Battle/Feature/Synergy/Scripts/SynergyEffects/GunslingerSynergyStatusEffect.cs` — `PhysicalAttack`→`Attack`.
8. `.../SynergyEffects/ArcanistSynergyStatusEffect.cs` — `MagicAttack`→`Attack`.
9. `.../SynergyEffects/ArcanistSpellPowerEffect.cs` — `MagicAttack`→`Attack`.
10. `.../SynergyEffects/WarmongerSynergyStatusEffect.cs` — `DamageReduction`→`Defense` 재배선. (Defense는 SeparatedMultiplicative 모드 → 수정자 값이 방어 비율에 가산. 밸런스 변동 수용. tier 키명 `lowDamageReduction`/`highDamageReduction` 및 내부 필드명은 데이터 바인딩 보존 위해 유지.)
11. `Assets/Scenes/Battle/Feature/Ui/StatInfoPanel/Scripts/StatInfoPanel.cs` — MainStats(6)/SubStats(4) 배열 10종.
12. `Assets/Scenes/Battle/Feature/Ui/StatInfoPanel/Scripts/UnitStatKindExtensions.cs` — GetDisplayName/FormatStatValue 10종. (표기 규칙 단일진실화는 Task-3 범위, 본 작업은 집합 구성원만 정정.)

## 데이터 마이그레이션
- SO `.asset`(UnitStatsByLevelData 인스턴스): `FormerlySerializedAs`로 물리 값 자동 계승(attack←physicalAttack, defense←physicalDefense). 마법/상태저항/받피감 직렬화 값 폐기.
- `Assets/Common/Data/Skills/SkillDefinitions/불화살.asset`: `statKind: 2`(구 MagicAttack)→`1`(Attack) 수정. `statKind: 5`(AttackSpeed)는 명시 int 보존으로 무변경.
