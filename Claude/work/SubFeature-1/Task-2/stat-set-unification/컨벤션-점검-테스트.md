## Pass 1 — 위반 식별

### UT-1 (AAA 구조 명료성)
- 신규 `StatSetUnificationTests`: Arrange/Act/Assert 빈 줄 분리 준수. 메타데이터 검증 케이스(S1 enum 수 등)는 Act+Assert 2단으로 자연스럽게 구분. → 위반 없음.

### UT-2 (매직 입력값 → 의미 있는 변수명)
- 신규: 입력값을 `attackPower`·`defenseRatio`·`skillCoefficient`·`damageDealtIncrease`·`critMultiplier` 등 의미 이름으로 끌어올림. 기대 산출값(`70f`·`126f`·`120f`)은 인접 주석으로 산식 근거 명시. → 위반 없음.
- `DamageCalculatorTests`(재작성)의 SetUp 인라인 리터럴(`100f` 등): 해당 파일의 **기존 관용**이며 각 케이스가 주석으로 산식을 문서화. 새로 도입한 위반이 아니고, 컨벤션 미명시 취향 변경(F-2)·포맷 변경(F-3)에 해당 → **수정 대상 제외**.

### UT-3 (테스트 한 개당 한 동작)
- 신규: 각 메서드 단일 동작. DoD-S6은 "표시 집합 10종 일치"·"중복 없음"을 2개 테스트로 분리. DoD-S4 `Get` 전수 검증은 *한 동작(모든 종류 조회 가능)* 의 도메인 순회 → 허용. → 위반 없음.

### UT-4 (매개변수화 테스트 활용)
- 신규: 동치분할을 `[TestCase]` 로 압축 — S1 제거 종류 부재(2케이스), S2 분리 종류 부재(4케이스)·단일 종류 존재(2케이스). 케이스 의미가 흐려지지 않는 선에서만 통합. → 위반 없음.

### 토큰 치환 7개 파일
- 기존 테스트 구조·명명·AAA를 보존한 채 능력치 식별자만 10종 API로 정렬(`MagicAttack`/`PhysicalAttack`→`Attack`, `DamageReduction`→`Defense` 등). 구조·동작 무변경이라 신규 컨벤션 위반 도입 없음. → 위반 없음.
