### 식별된 위반 (1건)

- **VR-1 (I-15 / 조용한 misinformation)**: `UnitStatsByLevelData.cs` 의 `[Header("치명/쿨감/저항/피해증가 ...")]` 가 제거된 "저항"(상태저항력) 을 여전히 명시 → 본 구현 단위 변경(상태저항 필드 제거)으로 부정확해진 그룹 라벨. 변경 인접 영역.

## Pass 2 — 위반 수정

- **VR-1 수정**: `[Header(...)]` → `"치명/쿨감/피해증가 (비율은 0~1 권장)"` 로 정정(제거된 "저항" 삭제). 에디터 인스펙터 라벨 cosmetic — 런타임 행위 무변경(F-1 무관).

## 보류(수정 안 함) 항목 — 근거

- **Warmonger 내부 필드명 `_lowReduction`/`_highReduction` + 티어 키 `lowDamageReduction`/`highDamageReduction`**: 받는피해감소→방어력 재배선 후에도 명칭에 "Reduction" 잔존. 그러나 티어 키는 시너지 데이터(.asset) 바인딩 식별자라 변경 시 데이터 마이그레이션·행위 영향(F-1/F-4) → DD 결정대로 보존. 내부 필드는 티어 키와 의미 연결 유지 위해 동반 보존. 명확한 컨벤션 위반 아님(설정된 경감 수치를 지칭) → 보류.
